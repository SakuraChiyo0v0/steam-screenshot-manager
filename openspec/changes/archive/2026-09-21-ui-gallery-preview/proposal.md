## Why

用户已选择第一套 UI 作为布局基础，要求日间/夜间主题，并采用第三套大图＋缩略图带的浏览交互。当前 启动自检面板不承担产品展示，需要独立可交互的 UI 基线供后续实施接入功能。

## What Changes

- 在现有 Electron React 渲染层实现游戏库、等比例截图网格、大图浏览、同步状态示例和设置界面。
- 增加日间/夜间主题、搜索筛选、示例收集对话框、前后/键盘切图与底部缩略图定位。
- 所有图库与任务数据为本地静态示例，持续显示预览标识；主题只保存界面偏好。
- 保留 工程基础阶段 诊断面板，通过设置按需进入；不自动运行数据库诊断。
- 保存视觉稿、素材说明、设计验收及后续接入说明。

## 非目标

不做 Steam 扫描、图片复制/导出、SQLite 图库读写、WebDAV 请求、后台同步、真实凭据保存。遵守 docs/product-plan.md、docs/architecture.md 的边界。本次是 UI 实现，不是 离线采集与归档阶段–后台可靠性阶段 功能完成。

## Capabilities

### New Capabilities
- gallery-ui-preview：图库界面、主题和图像浏览的示例交互。

## Impact

仅渲染层、图标依赖、预览配置与相关文档；不改主进程、预加载、数据库或公共通信契约。不提交、推送、部署。
