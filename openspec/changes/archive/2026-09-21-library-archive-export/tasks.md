## 2. 归档（本地收集）

- [x] 2.1 归档计划：只列没有可接受管副本的资产，支持按游戏/资产筛选。验证：单元测试断言归档后计划为空。
- [x] 2.2 复制与校验：流式复制同时算 SHA-256，与索引指纹核对后才发布。验证：指纹不符时不发布且 staging 无残留。
- [x] 2.3 不可覆盖发布：同文件系统临时文件 + 改名；目标已存在时校验内容，相同则补记录、不同则拒绝覆盖。验证：预置不同内容文件后归档失败且原文件不变。
- [x] 2.4 说明文件：`metadata/<accountKey>/<gameKey>/<sha256>.json`，只含展示与重建字段。验证：单元测试断言不含来源绝对路径。
- [x] 2.5 幂等与自愈：重复执行不重复复制；文件已发布而记录丢失时补记录。验证：两条单元测试。
- [x] 2.6 中断恢复：协作式取消保留已完成成果，重跑只处理剩余项。验证：单元测试 + 真机 500 张中断后续跑。
- [x] 2.7 启动对账：受管副本缺失标记 `present=0`，清理 staging 残留。验证：单元测试 + 真机对账检查 2,919 / 缺失 0。
