# 内存优化任务

## 1. 测量

- [x] 1.1 测量脚本 `docs/evidence/measure-memory.mjs`：CDP 取 JS 堆 / DOM 节点 / 事件监听器 / 图片数，分阶段驱动界面。
- [x] 1.2 按进程类型采样 RSS（main / renderer / gpu-process / utility）。
- [x] 1.3 建立基线：相册 600 张 602.5 MB、查看器 745.0 MB（GPU 410 MB）。

## 2. 优化

- [x] 2.1 迷你预览尺寸（200px）与 `ssm-asset://mini/` 通道。验证：4.5 KB/张，缩略图带改用它。
- [x] 2.2 缩略图带窗口化（当前项前后各 30 张 + 等宽占位）。验证：600 → 31 个图片元素，滚动几何正常。
- [x] 2.3 游戏封面改走缩略图通道。验证：相册阶段 GPU −96 MB。
- [x] 2.4 离屏卡片 `content-visibility: auto`。验证：包含在相册阶段收益内。
- [x] 2.5 去掉模态毛玻璃。验证：查看器阶段 GPU 410 → 195 MB。
- [x] 2.6 网格图片 `decoding="async"`。

## 3. 复测与交付

- [x] 3.1 同口径复测：相册 −102.8 MB（−17%），查看器 −220 MB（−30%）。
- [x] 3.2 截图确认去掉毛玻璃后的观感正常。
- [x] 3.3 `pnpm typecheck` / `pnpm test`（165 条）/ `pnpm build` 全绿。
- [x] 3.4 产出实施报告并提交。
