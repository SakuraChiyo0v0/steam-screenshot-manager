# A1 索引接入任务

验证方式写在每条任务里。本变更**不复制来源文件**，所有来源目录全程只读。

## 1. 准备

- [x] 1.1 建立本变更提案（proposal / design / specs / tasks）并通过 `openspec validate`。
- [x] 1.2 先把 UI 轮成果（`ui-gallery-preview`）单独提交，避免与本次接入改动混淆、也避免后续替换示例素材时丢失。

## 2. 解析层

- [x] 2.1 用 `@node-steam/vdf` 封装文本 VDF/ACF：`libraryfolders.vdf`（含 `apps` 子表）、`appmanifest_*.acf`、`screenshots.vdf`。验证：单元测试用内联样例覆盖正常、缺字段、损坏三种情况。
- [x] 2.2 自写二进制 `shortcuts.vdf` 读取器（类型字节 0x00/0x01/0x02/0x08），产出 `storedAppid → AppName` 映射与 gameID 换算。验证：单元测试断言 `(storedAppid << 32) | 0x02000000` 与真实目录名一致（用文档中已实测的两个 gameID 作为固定样例）。
- [x] 2.3 解析失败容错：任意 VDF/ACF 损坏时记录问题并继续，不中断扫描、不写回来源。验证：单元测试断言抛错被捕获且其余文件仍被处理。

## 3. 来源发现

- [x] 3.1 注册表发现：读取 `HKCU\Software\Valve\Steam` 安装路径并检查可用性；失败时回退常见路径并允许手动。验证：在本机真实 Steam 安装上实测发现成功。
- [x] 3.2 手动根目录登记：目录选择 + 宽松校验（存在 `userdata` 或 `steamapps`），重复登记同一目录不产生重复来源。验证：单元测试覆盖校验分支；手工验证选择离线样本目录可登记。
- [x] 3.3 账号枚举：列出 `userdata` 下全部账号并标注是否有 `760` 目录。验证：对离线样本断言 2 个账号、其中一个无截图。
- [x] 3.4 来源可用性：区分"来源不可达"与"来源没有截图"。验证：单元测试断言不可达时不更新文件存在状态。

## 4. 扫描与索引

- [x] 4.1 schema 迁移 v2：新增 `profiles`、`games`、`sources`、`assets`、`source_files` 与必要索引；迁移幂等、失败保留原库。验证：单元测试断言从 v1 升级、重复迁移不重复应用、失败回滚。
- [x] 4.2 扫描与哈希：目录枚举为主（VDF 只补元数据），排除 `thumbnails`，只取受支持扩展名；流式 `createReadStream` + SHA-256，不整文件入内存。验证：单元测试覆盖枚举与扩展名过滤；对离线样本实测耗时。
- [x] 4.3 幂等写入：`assets` 按 `(account_key, game_key, sha256)`、`source_files` 按 `(source_id, relative_path)` upsert。验证：单元测试断言重复扫描后各类计数不变。
- [x] 4.4 存在状态：成功扫描后把本次未见的来源文件标记为不存在；来源不可达时不更新。验证：单元测试覆盖两种情况。
- [ ] 4.5 进度与取消：已实现（阶段/已处理/总量/失败计数经事件推送，总量未知为 `null`；`shouldCancel` 在文件之间检查）。**但取消与进度形状没有自动化用例覆盖，未做端到端取消验证**。
- [x] 4.6 单文件失败不中断：读取或哈希失败记录明细并继续。验证：单元测试用不可读文件验证。

## 5. 查询与图片供给

- [x] 5.1 游戏列表统计：名称、显示键、安装状态、图片数、字节数、最新拍摄时间、封面资产 ID；只列有截图的游戏。验证：单元测试断言聚合数值与去重口径。
- [x] 5.2 资产分页查询：按游戏、账号、安装状态筛选，按拍摄时间或导入时间排序，稳定游标。验证：单元测试断言分页无重复无遗漏。
- [x] 5.3 资产详情：展示元数据 + 时间来源 + 原图是否存在；**不返回任何绝对路径**。验证：单元测试断言返回结构中不含来源根路径。
- [x] 5.4 `ssm-asset` 协议：解析 assetId → 查库 → `resolve` 后校验位于来源根内 → 返回内容；缩略图优先 `thumbnails`，缺失回退原图。验证：单元测试覆盖正常、未知 ID、`..` 越界、根外路径四种情况。
- [x] 5.5 CSP：`img-src` 加入 `ssm-asset:`，不放宽脚本与连接来源。验证：开发运行中图片正常加载且控制台无 CSP 报错。
